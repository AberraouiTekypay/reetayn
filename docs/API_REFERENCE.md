# Reetayn REST API Reference

## 1. Webhook Intake

### `POST /api/webhooks/stripe`
Ingests real-time events from Stripe. Requires raw body and valid `stripe-signature` header.

#### Headers
| Header | Type | Description |
| :--- | :--- | :--- |
| `stripe-signature` | `string` | Cryptographic signature generated by Stripe using HMAC-SHA256. |

#### Response
```json
{
  "received": true,
  "eventType": "invoice.payment_failed",
  "durationMs": 42
}
```

## 2. Customer Risk Intelligence

### `GET /api/customers/risk`
Returns the evaluated churn risk, payment diagnostics, and renewal status for a given Stripe Customer ID.

#### Query Parameters
| Parameter | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `customerId` | `string` | **Yes** | Stripe Customer ID (e.g. `cus_xxx`). |
| `merchantId` | `string` | No | Internal Reetayn Merchant CUID. |
| `stripeAccountId` | `string` | No | Connected Stripe account ID (`acct_xxx`). |

## 3. Instant Recovery Link Generation

### `POST /api/rescue/generate-link`
Creates a single-use, pre-authenticated Stripe Customer Portal session configured exclusively for payment method updates.

#### Request Body
```json
{
  "stripeCustomerId": "cus_AcmeCorp891",
  "merchantId": "clxx1938b0000abcde12345",
  "returnUrl": "https://reetayn.com/rescue/success",
  "actionType": "MANUAL_DRAWER_TRIGGER"
}
```

#### Response (`200 OK`)
```json
{
  "success": true,
  "url": "https://billing.stripe.com/p/session/live_portal_sample123",
  "sessionId": "bps_1OabcXYZ",
  "logId": "clyy9876a0000fedcba9876",
  "customerId": "cus_AcmeCorp891",
  "actionType": "MANUAL_DRAWER_TRIGGER"
}
```

## 5. Stripe Connect / App OAuth Callback

### `GET /api/auth/callback`
Handles OAuth authorization code exchange following merchant installation of the Reetayn Stripe App.

#### Query Parameters
| Parameter | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `code` | `string` | **Yes** | Authorization code provided by Stripe. |
| `state` | `string` | No | Anti-CSRF verification token. |

#### Response
Redirects with HTTP 302 to `/dashboard?connected=true&account=acct_xxx`.
